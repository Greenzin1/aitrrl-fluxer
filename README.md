# aitrrL - Fluxer Bot

Bot para o Fluxer, porta do aitrrL original.

## Comandos

| Comando | Descricao |
|---------|-----------|
| `!aitrrl` | Sobre o bot |
| `!ping` | Latencia |
| `!calc <expr>` | Calculadora |
| `!oitobola` | Bola 8 magica |
| `!reverso <texto>` | Reverte texto |
| `!ship @u1 @u2` | Compatibilidade |
| `!moeda` | Joga moeda |
| `!dado` | Joga dado |
| `!poll <pergunta>` | Enquete |
| `!compliment` | Elogio |
| `!insult` | Zoeira |
| `!perfil` | Seu perfil |
| `!rep @user` | Dar reputacao |
| `!daily` | Recompensa diaria |
| `!coins` | Suas moedas |
| `!ranking` | Leaderboard |
| `!avatar` | Avatar |
| `!ajuda` | Ajuda |
| `!stats` | Stats do bot |

## Deploy

1. Crie um bot em https://fluxer.app
2. Copie o token
3. Suba no Railway ou rode localmente com `node bot.js`
